## Notes for Higgsfield

- **Aspect ratio:** All reels are 1080x1920 (9:16 vertical for TikTok/Reels)
- **Voiceover:** Will be added in post (Higgsfield can generate or you provide)
- **Duration:** Leave 0.5-1s buffer at end for app branding
- **UI mockups:** If Higgsfield struggles with app interfaces, provide real app screenshots to composite
- **Car footage:** Use stock automotive footage or generated cars if realistic enough
- **Transitions:** Smooth cuts, fades, or wipes between scenes
- **Color grading:** Dark mode aesthetic (blacks, dark grays, warm oranges for accents)

## Usage

1. Copy one prompt at a time into Higgsfield's Cinema Studio or Supercomputer
2. Adjust length/pacing as needed based on output
3. Request regenerations if timing is off or scenes need tweaking
4. Export as vertical MP4 (1080x1920)
5. Add voiceover in post (or Higgsfield can generate with voice API if available)
