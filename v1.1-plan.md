## If 1.0 is rejected — likely fixes

| Likely rejection reason | Fix |
|-------------------------|-----|
| **Account required / no guest mode (4.1.1)** | App Review Notes must explicitly state: *"TorqueDen is a UGC platform — all core features (garage, build log, feed, meets, forums) are tied to the user's account. A guest mode is not technically feasible."* Apple exempts apps where this is inherent. Include test account credentials in the same notes field. |
| IAP not demonstrable in review | Ensure membership screen + upgrade sheet work in sandbox; add sandbox test account to App Store Connect |
| Missing privacy detail | Confirm all data types declared in App Privacy (photos, user content, identifiers) |
| Links in posts flagged | Confirm `url_launcher` only opens user-typed links, not injected URLs |
| Sign in with Apple missing | Not currently required (email/password only); add if rejected for this |
